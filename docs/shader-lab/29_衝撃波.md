# 29. 衝撃波 — 物を描かず、読む位置をずらす

![衝撃波](images/29_shockwave.gif)

爆風で空気が歪む表現です。
**歪んだ物そのものは何も描いていません。**
背景を読む位置をずらしているだけです。

背景が市松模様なのは、歪みが目で追えるようにするためです。

ソース : [`shaders/lab/29_shockwave.hlsl`](../../shaders/lab/29_shockwave.hlsl)

---

## 1. 歪みの正体

```hlsl
float2 warpedUv = uv + direction * displace;
float3 color = Background(warpedUv);
```

`uv` の位置を塗るのに、**別の場所 `warpedUv` の色**を持ってきます。
すると絵が動いたように見えます。

これはレンズ・陽炎・水中の揺らぎとまったく同じ仕組みです。
[07 章](07_ドメインワープ.md)のドメインワープを、
生成した模様ではなく**実際の画面**に対して行っています。

> **ゲームでは背景を 1 枚のテクスチャに描いてから、これを掛けます。**
> [25 章](../tutorial/25_ポストプロセス.md)で作った中間バッファが、
> そのまま歪みの入力になります。

---

## 2. リングを作る

```hlsl
float radius = time * speed;                          // 半径は時間に比例
float ring   = 1.0f - saturate(abs(distance - radius) / width);
ring = pow(ring, 2.0f);
```

`abs(距離 − 半径)` は「リングからどれだけ離れているか」です。
0 のときリング上、`width` を超えると 0 になります。

```
distance:  0 ────── radius ────── ∞
ring:      0        1              0
```

`pow` で縁を鋭くします。指数が小さいとぼんやりした波、
大きいと薄い膜のような波になります。

### エネルギーは薄まる

```hlsl
float decay = 1.0f / (1.0f + radius * radius * 1.2f);
```

輪が広がるほど、同じエネルギーが長い円周に配られます。
**半径の 2 乗で割る**とそれらしくなります。
これが無いと、画面の端まで同じ強さで走って不自然です。

---

## 3. 2 発重ねる

```hlsl
float2 wave1 = Shockwave(p, center, local,              1.35f, 0.16f);
float2 wave2 = Shockwave(p, center, max(local - 0.12f, 0.0f), 1.10f, 0.10f);
```

わずかに遅らせた 2 発目を重ねると、余韻が出ます。
速さと幅も変えているので、時間が経つほど 2 本が離れていきます。

VFX が「1 つの式」ではなく「**ずらした複数の層**」でできている、
という点は [32 章](32_爆発.md)でも同じです。

---

## 4. 色収差

```hlsl
float2 shift = direction * displace * 0.22f;
color.r = Background(warpedUv + shift).r;
color.b = Background(warpedUv - shift).b;
```

赤と青だけ、ずらす量を変えて読み直します。
**歪みが強いところほど縁が虹色に割れる**ので、
「レンズを通して見ている」感じが強まります。

実際のガラスの分散（波長ごとに屈折率が違う）を、
3 チャンネルぶんだけ真似たものです。

---

## 5. つまずきやすい点

### 縦横で歪みの量が変わる

`uv` は 0〜1 の正方形なので、そのまま足すと
**横長の画面では横方向の歪みが強くなります**。

```hlsl
float2 warpedUv = uv + direction * displace
                * float2(g_resolution.y * g_resolution.z, 1.0f);
```

`高さ / 幅` を掛けて打ち消します。

### 画面の外を読む

`warpedUv` が 0〜1 の外へ出ると、実際のテクスチャでは
サンプラーの設定次第で端が伸びたり繰り返したりします。
ここでは `saturate` で端に張り付かせています。

### 歪みを強くしすぎる

`displace` が 0.2 を超えると、背景が明らかに割れて見えます。
**0.05〜0.12 くらいが「歪んでいるのに気づく」上限**でした。
効果は強さではなく、鋭さと減衰で出します。

---

## 6. ここから作れるもの

| やりたいこと | 変えるところ |
|------------|------------|
| 陽炎・熱気 | `displace` をノイズにし、上へ流す |
| 水中 | 低い周波数の `sin` を 2 方向に重ねる |
| 銃口の衝撃 | 円ではなく前方向だけの扇形に |
| 重力レンズ | `displace` を `1/distance` に |
| 被弾表現 | 画面全体に短い 1 発 ＋ 色収差を強く |
