# 参考文献・出典

仕様の細かい値（定数の意味、必須の呼び出し順序など）は、
**必ず一次情報である Microsoft Learn の公式ドキュメントで確認**しています。

各解説ページの末尾にも、そのページで参照した資料を個別に記載しています。

## 引用の方針

- **仕様の断定**（「〜しなければならない」「既定値は〜」）を書くときは、
  必ず Microsoft Learn の該当ページを確認し、そのページのリンクを添える。
- **本リポジトリ独自の判断**（クラス分割、単純化した箇所）は、
  出典ではなく「本プロジェクトの設計判断」であることを明記する。
- **計測結果**は、測定した環境（GPU、ビルド構成、VSync の有無）を併記する。
  他環境で再現しない可能性があるため。
- 図はすべて本リポジトリで作成したもの（`docs/assets/` の SVG、Mermaid）。
  外部の図を転載していない。
