## この学習プロジェクトの方針

### 1. 「動くコード」より「分かるコード」

ライブラリ（DirectXTK12、`d3dx12.h` など）を意図的に使わず、
生の DirectX 12 API を直接呼んでいます。
ヘルパーが隠している処理こそ、学習で理解すべき対象だからです。

### 2. 解説はコメントではなくドキュメントに書く

コード中のコメントは **一般的な粒度**（`<summary>` と、
間違えると壊れる点の注意だけ）に抑えています。
「なぜそうするのか」の長い説明は [tutorial/](tutorial/) にまとめました。

コードを追うときはコメント、仕組みを理解したいときは解説、
と使い分けてください。

### 3. 段階的に高度化する

第 1 段階では、あえて非効率でも単純な実装を選んでいます。

| 項目 | 現在の実装 | 今後の改善 |
|------|-----------|-----------|
| GPU 同期 | フレームバッファリング | バッファ 3 枚化 |
| 頂点バッファ | DEFAULT ヒープ＋ステージング転送 | 形状データの外部ファイル読み込み |
| テクスチャ | 全テクスチャに CPU でミップを生成。異方性フィルタ 8x | コンピュートシェーダーでの生成、.dds、ブロック圧縮 |
| 画像の読み込み | WIC で PNG / JPEG などを読む | ミップマップ、圧縮テクスチャ |
| 描画対象 | 立方体と床の 2 個を固定で持つ | シーングラフ、マテリアル別の並べ替え |
| ライティング | 平行光源 1 つの PBR ＋ IBL（正距円筒図法の環境マップ）| 複数光源、HDR 環境マップ、GGX 重要度サンプリング |
| 色空間 | HDR の中間バッファに描き、後処理で露出・圧縮 | 自動露出、ACES / AgX、被写界深度 |
| 影 | シャドウマップ 1 枚（2048²）＋ 3×3 の PCF | カスケード化、やわらかい影 |
| 入力 | キーボードとマウス。割り当ては固定 | ゲームパッド、キー割り当ての変更 |
| モデル読み込み | OBJ と glTF 2.0（形・基本色・金属度・粗さ・法線マップ）| 遮蔽マップ、アニメーション、スキニング |
| シェーダー | 実行時コンパイル（FXC）。手順は `ShaderCompiler` に集約 | 事前コンパイル / DXC |

### 4. 最適化は「測ってから」判断する

フレームバッファリングは、**この段階では速くなりませんでした**。
三角形数枚では GPU の仕事が軽すぎて、待ち時間が存在しないためです。

その計測結果もそのまま
[05 章](tutorial/05_GPUへの命令と同期.md#5-実測してみた結果)
に記載しています。「効くはずだ」で終わらせず、
**測って確かめる習慣**そのものを学習対象としています。

### 5. 出典を明記する

仕様の断定は必ず一次情報（Microsoft Learn）で確認し、
各ページの末尾に参照したページを記載しています。
図はすべて本リポジトリで作成したもので、外部の図は転載していません。

詳細は [参考文献](misc/参考文献.md) を参照してください。

### 6. 図は SVG か Mermaid で描く

アスキーアートは使いません。

| 用途 | 使うもの |
|------|---------|
| 処理の流れ・依存関係・状態遷移 | Mermaid |
| メモリ配置・座標系・タイムライン | SVG（[assets/](assets/)） |
| 実行結果の証拠（対照実験など） | PNG（[assets/](assets/)） |
| ディレクトリ構成・コンソール出力 | コードブロック |

どちらもテキストなので、Git で差分が追えます。
