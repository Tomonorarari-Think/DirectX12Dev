# サンプルテクスチャ

このフォルダの画像は、**すべて本リポジトリで生成したもの**です。
外部から取り込んだ素材は含まれていません
（生成スクリプトの内容は [解説 17 章](../../docs/tutorial/17_画像を読み込む_WIC.md) を参照）。

| ファイル | 大きさ | ねらい |
|---------|-------|--------|
| `uv-grid.png` | 512 × 512 | 実際に貼るテクスチャ。UV の向きが目で分かる |
| `checker.png` | 256 × 256 | デコード結果の検証用。コード生成の模様と同一 |
| `sphere-bands.png` | 256 × 256 | 球に貼る横縞。回転と UV の連続性が分かる |
| `environment.png` | 512 × 256 | IBL 用の環境マップ（正距円筒図法）|

## uv-grid.png

**向きが分かる**ことを最優先にした絵です。

- **UV (0,0) の角に赤い印**（白丸つき）
- **V が増える向きに矢印**
- 上端の並びに緑の点（左右反転も分かるように）

上下や左右が反転していれば、印と矢印の位置ですぐ気付けます。
市松模様のような対称な絵では、この確認ができません。

床の UV は `(0,0)` が奥左、`(1,1)` が手前右になるよう作ってあるので、
**赤い印が奥の左、矢印が手前向き**なら正しい配置です。

## checker.png

`CreateCheckerboardPixels()` がコードで作るものと**まったく同じ模様**です。

- 256 × 256、1 マス 32 ピクセル
- 明るいマス `(235, 235, 235)` / 暗いマス `(60, 60, 70)`

同じ絵を「ファイルから読んだ場合」と「コードで作った場合」で描き比べ、
**画素単位で一致するか**を確かめるために置いています。

一致すれば、PNG の展開・RGBA の並び・1 行のバイト数（ストライド）が
すべて正しいことが同時に確認できます。

> ただし**上下の向きだけは確認できません**。
> 反転しても同じ模様になるためです。向きの確認は `uv-grid.png` で行います。

## environment.png

IBL（[解説 21 章](../../docs/tutorial/21_IBL_環境マップ.md)）で使う環境マップです。
**正距円筒図法**で、横が水平方向の一周、縦が真上から真下までを表します。

- 上半分 … 空。天頂ほど濃い青、地平線に近いほど淡い
- 下半分 … 地面。茶色寄りで、真下ほど暗い
- 太陽 … **平行光源と同じ向き**に置いてある

太陽の向きを光源と合わせているのは、
**映り込みと直接光のハイライトが同じ場所に出る**ようにするためです。
ずれていると「光源はここなのに空の太陽はあちら」という違和感が出ます。

空と地面で色を大きく変えてあるのは、
**面の向きによって環境光の色が変わる**ことを目で確認するためです。
上を向いた面は青く、下を向いた面は赤みを帯びます。

> **8 bit の PNG なので明るさは 1.0 で頭打ちです。**
> 太陽の眩しさを出すには HDR（`.hdr` / `.exr`）が要ります。
